# Desafio de Aprendizagem Ativa com NotebookLM 🚀

Este projeto foi desenvolvido como parte de um desafio da **DIO**, focado em utilizar o NotebookLM para criar um ecossistema de aprendizagem ativa sobre **Renda Fixa**.

## 🎯 Objetivo
O objetivo é transformar conceitos financeiros complexos em um guia acessível para iniciantes, utilizando curadoria de fontes oficiais e engenharia de prompts.

## 📂 Conteúdo do Repositório
- `Miniguia_Renda_Fixa.docx`: Documento consolidado com objetivos, glossário e prompts.
- `Fontes/`: Links para o Banco Central, Tesouro Direto, InfoMoney e XP.

## 🛠️ Metodologia e Tecnologias
Para a construção deste material, utilizei uma abordagem de **Co-criação Humano-IA**, onde:
1. Usei IA Generativa para validar a arquitetura da informação e organizar a estrutura do guia.
2. Apliquei curadoria manual em fontes de autoridade (BCB, Tesouro Direto).
3. Estruturei prompts específicos para testar a persona de "Agente Financeiro" dentro do NotebookLM.

## 🤖 Prompts Utilizados
No documento, você encontrará os prompts exatos usados para extrair rankings de investimentos, análise de taxas e explicações intuitivas.
